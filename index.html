Second Backend · Token Exchange

Доступ ко второму сервису

Ваш токен выдан для alem. Второй сервис (second) его не примет — сначала токен нужно обменять в Keycloak на токен для second.

  1. 1
    Проверить текущий токен в second
    Отправляем токен alem во второй сервис. Он должен отказать: токен выдан не для него.
  2. 2
    Обменять токен через Keycloak
    Second передаёт токен alem в Keycloak и получает взамен новый токен — уже для себя.
  3. 3
    Войти в second с новым токеном
    Отправляем новый токен во второй сервис. Теперь он должен пустить.
